A pure-stdlib Python program that draws the world news of Tuesday 24 November 2026 as a one-page newspaper front page — masthead, lead story on the Russian corvette destroyed at Benghazi, and six more stories from Washington, the Strait of Hormuz, Silicon Valley, Indonesia, Gaza and Geneva — and writes it to `/output/entry.png`.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The run is deterministic (same bytes every time), uses no network and no third-party packages, and finishes in under a second.
